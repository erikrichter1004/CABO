# CABO Online V1

GitHub Pages PWA, PeerJS WebRTC mit öffentlichem PeerJS-Signalisierungsdienst (kein eigener Server). 4-stellige Codes, Lobby, Host-Autorität, Grundzüge und Punktewertung als frühe Testversion.

**Wichtig:** Nicht vollständig: Spezialfähigkeiten, Anfangsblick, mehrfache Tauschaktionen, Ready-Flow, Gastgeberwechsel, sichere Wiederverbindung und vollständige Regeln fehlen. Keine echte Sicherheit gegen manipulierte Clients garantiert. Die Mehrspieler-Verbindung wurde noch nicht mit mehreren Geräten getestet.

GitHub Pages unter Settings → Pages → Deploy from a branch → main/root aktivieren. Öffentlicher PeerJS-Dienst kann Ausfälle haben. Keine Zugangscodes oder geheimen Kartenwerte als Authentifizierung behandeln.
